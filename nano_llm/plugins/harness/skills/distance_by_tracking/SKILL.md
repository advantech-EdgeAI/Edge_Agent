## 流程

1. **選相機**：只有深度相機能量距離，`list_camera_sources` 會在這類來源後面標示 depth。物體要在那台相機的畫面裡；不確定時先 `read_camera_frame` 看一下。
2. **選方法**（只選一個，不要先試一個再換另一個）：
   - **常見、有通用英文名稱的東西**（人、杯子、瓶子、手機、包包、椅子、筆電）：呼叫 `start_tracking(objects="英文名稱", keep_tracking=false)`（不填 source 就是深度相機）。回覆直接給距離。回覆是 `weak match` 時不會給距離，也不要用它的位置回答：改用下面的框選。
   - **其他東西**（沒有常見名稱的：展品、商品、標誌、自製零件、玩具、任何叫不出常見名稱的東西）：直接 `read_camera_frame(source=深度相機)`，在畫面上框住**整個物體**（不要包含背景或旁邊的東西，0–1000 座標，左上 0,0），呼叫 `track_object_in_frame(box="x1,y1,x2,y2", label="英文短名", keep_tracking=false)`，例如 `box="420,300,560,610"`（不填 source 就是你剛看的那台；同一次看了兩台以上要填 source）。
3. **看回覆**：回覆直接給距離與畫面位置。框選的回覆附一張畫出量到的框的圖：框在你要的物體上才用這個距離；框到別的東西，就重新 `read_camera_frame`、在新畫面上框一次再呼叫（同一個 label）。名稱量不到（`not seen` 或 `weak match`）時，改用框選。
4. **回答**：1 公尺以內以公分回報，照著念（47 cm 念「四十七公分」）。回覆標示「可能不準」時，告訴使用者這個數字可能不準。
5. **要持續追蹤**（「幫我盯著它」）：同樣的工具，`keep_tracking` 不填（預設持續追蹤）。

## 常見錯誤

- **在沒有深度的相機上量**：回覆會說 no depth on this camera，改用深度相機。回覆是 no valid depth for this object 時，是物體太近、反光或透明，照實告訴使用者量不到。
- **框偏了**：框選後回覆 Nothing matched 時，附圖的紅框就是你框的位置，重看畫面、框住整個物體再呼叫一次（同一個 label），不要推給光線。
- **切換目標**：開始追蹤新的東西會取代原本追蹤的（框選的也是）；使用者說「也、一起、再加」時才加 `add=true`。
- **框太大**：框包含背景時，偵測器會學到背景，距離會變成遠處的東西。
- **反覆用同一個名稱**：名稱找不到或只是 weak match 時，改用框選，不要重複同一個呼叫。
